# PayFlow Frontend

React + Vite. Интерфейс для существующего FastAPI backend.

## Запуск на Windows или macOS

Нужен Node.js 22.12+ (подойдёт Node.js 24 LTS).
Распакуйте папку `payflow-frontend` рядом с `app`, `compose.yaml` и `alembic.ini`.
Backend и PostgreSQL должны быть запущены. В терминале backend:

```sh
python -m uvicorn app.main:app --reload
```

В другом терминале:

```sh
cd payflow-frontend
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173 . Адрес API по умолчанию: http://127.0.0.1:8000 .
Входите существующим аккаунтом или зарегистрируйте новый.

## Что работает

- Регистрация с серверной проверкой данных и вход по email/паролю.
- JWT в sessionStorage вкладки, заголовок Authorization: Bearer для защищённых запросов.
- Выход и переход на вход при 401 / истечении токена.
- Мой профиль и копирование ID для владельца другой организации.
- Список своих организаций, поиск по названию, обновление списка.
- Создание организации и просмотр её информации.
- Добавление существующего пользователя по UUID как manager или viewer.
- Отображение ошибок 403, 404, 409, 422, сетевых ошибок; блокировка повторной отправки формы.
- Адаптивная вёрстка для телефона и компьютера.

Список участников, клиенты, счета и платежи ещё не подключены: соответствующие эндпоинты не были готовы на этапе создания интерфейса. Роль текущего пользователя API организаций пока не возвращает, поэтому кнопку добавления видят все участники, а сервер проверяет owner и возвращает 403 остальным. Данные не подменяются демонстрационными.

## Подключение

Vite направляет запросы `/api/*` на локальный FastAPI, удаляя префикс `/api`. Это позволяет запускать интерфейс без изменения CORS backend. Прокси работает при `npm run dev` и `npm run preview`.

Используемые эндпоинты:

| Метод | Путь |
|---|---|
| POST | /auth/register |
| POST | /auth/login |
| GET | /auth/me |
| GET, POST | /organization |
| GET | /organization/{organization_id} |
| POST | /organization/{organization_id}/members |

Через `/openapi.json` автоматически распознаются `/organization` и `/organizations` (с завершающим слешем или без), а также `/member`, `/members`, `/memberships` для добавления. Если OpenAPI отключён, используется `/organization` и `/members`.

Для другого адреса или путей скопируйте `.env.example` в `.env`, измените значения и перезапустите Vite. В `.env` фронта не нужен JWT_SECRET_KEY: секрет подписи остаётся только на backend.

```dotenv
API_TARGET=http://127.0.0.1:8000
VITE_ORGANIZATIONS_PATH=/organization
VITE_MEMBERS_SEGMENT=members
```

## Проверка сборки

```sh
npm run build
npm run preview
```

Production-сборка появится в `dist`. Для публикации на настоящем сервере настройте reverse proxy `/api` к backend и HTTPS; один статический хостинг без API-прокси недостаточен. sessionStorage — выбор для локальной учебной версии; JS может читать токен, поэтому не подключайте недоверенные скрипты.

## Структура

- `src/api.js` — HTTP, Bearer-токен, ошибки и определение путей.
- `src/main.jsx` — React-компоненты и формы.
- `src/style.css` — стили и адаптивность.
- `vite.config.js` — локальный proxy к FastAPI.

Ваш localhost недоступен из среды автора. Сборка проверена отдельно; подключение к реальному backend необходимо проверить после запуска на вашем компьютере.
